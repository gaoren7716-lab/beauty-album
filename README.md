# 美人画册 · beauty-album

把「一个完整可复现的人物配方」压成三位编号，像记电话号码一样记住一个形象。
**80 编号 × 40 主题 × 8 门类 × 4 模式 = 102,400 种组合，× 5 种平台语法 = 512,000 份可直接复制的词面。**

## 在线画廊（推荐）

**https://gaoren7716-lab.github.io/beauty-album/**

筛选 · 看八面细节 · 一键复制 · 组图 · 抽卡。离线用：下载本仓库双击 `index.html`（单文件、零依赖、不联网也能跑）。

## 怎么用

1. **敲编号**：输入 `041` → 出全套词面 → 复制，贴进任意出图模型
2. **换轴**：换主题 / 门类 / 模式，词面现算；没主意就抽卡，看中哪根轴锁哪根
3. **不越界**：骨相 / 肤质 / 眼目 / 形体 / 气质是身份层，改了就不是这个编号；商用前看授权档（R0 自由 / R1 署名 / R2 仅参考 / R3 改写后用）
