# 美人画册 · beauty-album

把「一个完整可复现的人物配方」压成三位编号，像记电话号码一样记住一个形象。

**80 个编号（原型段 48 + 全球段 32）· 40 个主题 · 8 种门类 · 4 种呈现模式 · 5 种平台方言。**
编号 × 主题 × 门类 × 模式 = **102,400 种组合**，× 5 种平台语法（SD / MJ / FLUX / 自然语言 / GPT）
= **512,000 份可直接复制的词面**（界面顶栏现算，轴一补条目它就变）。

## 打开

| 入口 | 用途 |
| --- | --- |

| [画廊图鉴](GALLERY.md) | 在 GitHub 上直接翻全部 80 个编号 —— 有实拍图的放图，没图的放色卡 |

## 三步用法

1. **敲编号**：输入 `041` → 出全套词面 → 复制，贴进任意出图模型
2. **换轴**：详情页换主题 / 门类 / 模式，词面现算；敲「东古典·清」按名字也能找
3. **抽卡**：没主意时四轴随机抽一组，看中哪根轴锁哪根

## 编号是什么

- **身份层恒定**：骨相 / 肤质 / 眼目 / 形体 / 气质 —— 编号发布后永不改变
- **内容层可换**：主题给场景 / 发型 / 妆造；门类改画法（照片、油画、工笔、动漫、3D…）；模式管版式
- 编号是**给记忆用的**：短、能敲、能念、永不改号 —— 记得住 041，就不用记二十个形容词

## 授权与实测（两条规矩）

- 每条编号显式标授权档 **R0 自由 / R1 署名 / R2 仅参考 / R3 改写后用**，商用前先看详情页
- 带实拍配图的编号都在 `test` 里写明**出图模型**与 hit/miss；没留模型出处的标 ⏳ 待核实，不计入已实测
